Welcome to CampusFix

CampusFix provides a simple platform for reporting and managing campus issues.

How CampusFix Works

  1. Students report campus issues.
  2. CampusFix checks for duplicate issues.
  3. Duplicate reports generate notifications.
  4. Administrators manage and resolve issues.

Key Features

  • Issue reporting
  • CRUD-based issue management
  • Duplicate issue detection
  • Student notifications
  • Admin notifications
  • JWT authentication
  • Role-based authorization
  • MySQL persistence
